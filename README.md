# بات فارسی تلگرام برای پنل سنایی / 3x-ui

این پروژه یک نسخه‌ی پایه اما قابل اجرا از بات فروش و مدیریت سرویس است:

- رابط فارسی برای کاربر، همکار و ادمین
- اتصال به پنل سنایی/3x-ui برای ساخت کلاینت
- پرداخت کارت‌به‌کارت با ارسال رسید و تایید ادمین
- پرداخت ارزدیجیتال با نمایش کیف پول، ثبت TXID/رسید و تایید ادمین
- نقش همکار برای ثبت سفارش مشتری
- ذخیره‌سازی محلی با SQLite

## راه‌اندازی سریع

1. وابستگی‌ها را نصب کن:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

2. فایل نمونه تنظیمات را کپی کن:

```powershell
Copy-Item .env.example .env
```

3. مقدارهای داخل `.env` را کامل کن:

- `BOT_TOKEN` توکن بات تلگرام
- `ADMIN_IDS` شناسه عددی تلگرام ادمین‌ها
- `PANEL_BASE_URL` آدرس پنل سنایی، همراه با web base path اگر داری
- `PANEL_USERNAME` و `PANEL_PASSWORD`
- `PANEL_DRY_RUN=false` برای اتصال واقعی به پنل
- `CARD_NUMBER` و `CARD_HOLDER`
- `CRYPTO_WALLETS_JSON`
- `PLANS_JSON`

4. بات را اجرا کن:

```powershell
python -m src.main
```

## نکته اتصال سنایی

اتصال پنل بر پایه API رسمی 3x-ui ساخته شده است:

- ورود: `POST /login`
- ساخت کلاینت: `POST /panel/api/inbounds/addClient`

برای تست بدون ساخت سرویس واقعی، مقدار `PANEL_DRY_RUN=true` بگذار. وقتی اطلاعات پنل درست شد، آن را `false` کن.

## مسیر پرداخت

در نسخه فعلی پرداخت‌ها دستی تایید می‌شوند:

- کارت‌به‌کارت: کاربر/همکار رسید یا کد پیگیری می‌فرستد، ادمین تایید می‌کند.
- ارزدیجیتال: بات آدرس کیف پول و مبلغ تقریبی USDT را نشان می‌دهد، کاربر TXID یا اسکرین‌شات می‌فرستد، ادمین تایید می‌کند.

بعد از تایید ادمین، بات کلاینت را در پنل می‌سازد و لینک سابسکریپشن را به کاربر یا همکار ارسال می‌کند.

## اضافه کردن همکار

ادمین داخل بات گزینه «افزودن همکار» را می‌زند و شناسه عددی تلگرام همکار را وارد می‌کند.

## مرحله بعد پیشنهادی

اتصال خودکار به درگاه کریپتو مثل Cryptomus یا NOWPayments، و اضافه کردن تایید وبهوک، روی همین ساختار پرداخت قابل اضافه شدن است.
